# Phase 10L-4 Scientific Boundaries

| Family | Allowed | Not supported by interpretation alone |
| --- | --- | --- |
| Dataset | counts, missingness, declared ranges/statistics/warnings | causality, discovery, best-material claims |
| ML | exact metrics and artifact-declared uncertainty facts | production readiness, generalization guarantee |
| Structure | computed lattice, symmetry, coordination/RDF/XRD facts | stability, phase/structure confirmation, bond truth |
| Phonon | frequency/path/DOS facts and explicit negative-mode presence | unconditional stability, anharmonic or phase-transition claims |
| Volumetric | quantity kind, scalar range, unit/reference, source warnings | Bader charge, charge transfer, topology, uncomputed integrals |

These boundaries constrain both deterministic and provider modes.
