# Phase 10L-4 Grounding Validator

Validation recomputes source and bundle identity, evidence references, entity
scope, allowlisted predicates, numeric literals, units, comparisons,
qualifiers, partial-result limitations, and forbidden-conclusion policy.
Cross-job/project/dataset evidence, stale hashes, failed or blocked outputs,
provider-created evidence IDs, non-finite numbers, executable text, paths, and
URLs are rejected.

Scientific conclusions such as unconditional stability, phase/structure
confirmation, production readiness, causal claims, Bader charge, charge
transfer, chemical-bond truth, or an uncomputed best material are not valid
Phase 10L-4 claims.
