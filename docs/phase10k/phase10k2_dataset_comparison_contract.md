# Phase 10K-2 Dataset Comparison Contract

Comparison is available only for two explicit profiled table resources or one
profiled table plus one explicit group column and two distinct group values.
Row order, percentages, filenames, and prompt wording never infer a split.

The result records binding mode, exact resource/group identity, sample counts,
shared and side-only element coverage, and common property summaries. Chemistry
uses the same canonical identities as the main product. A property comparison
is valid only when both profiled units are equal; mismatches remain visible and
are not converted or compared. Missingness is reported per side.

This phase performs descriptive exploration only. It does not run significance
tests, domain-shift scores, leakage detection, model metrics, embedding, or
clustering. The comparison never labels one dataset better, scientifically
valid, representative, or erroneous.
