# Phase 10K-3 Materials ML Evaluation Evidence

This evidence pack was generated from bounded local fixtures through Material
Data Profile 2.0, Mock Planner, persisted validated AnalysisPlan,
QueueWorkerRuntime, Registry adapters, artifact persistence, API retrieval, and
the current frontend product. It includes deterministic regression,
uncertainty, and classification cases; 4, 5,000, and 100,000-row performance
records; Chromium, Firefox, WebKit, and mobile captures; and inert security and
network audits.

The results evaluate supplied model-output data. They do not train models,
establish material validity, infer causal quality, or execute artifact code.
