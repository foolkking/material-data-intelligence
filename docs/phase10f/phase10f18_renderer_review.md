# Renderer and UI Review

The mapper does not infer an alternate image. Complete periodic bonds are replicated over renderer-local supercells and deduplicated by full endpoint identity. No clipped half-edge is drawn. Bond visibility uses one bounded shared line geometry and existing disposal paths.

The site inspector table exposes offset, distance, source, authoritative state, and keyboard-operable highlight. Mobile layout uses the existing responsive inspector. JSON fallback, measurement modes, PNG export, context-loss handling, and v1 rendering remain separate and unchanged.
