# Phase 10F-16 Integrated Plan

Phase 10F-16 extends the validated production viewer with bounded site picking,
canonical site inspection, Cartesian distance/angle/dihedral measurements, local
PNG capture, artifact downloads, and explicit legacy guidance. Backend execution
and the canonical artifact contract remain unchanged. Selection is capped at four
sites, history at twenty results, and export at 4096 by 4096 effective pixels.

The implementation order was pure math/state, renderer picking/overlays, React
inspection UI, browser evidence, then audit and regression closure.
