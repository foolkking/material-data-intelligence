# Periodic Security Review

Untrusted lattice and site data remain behind canonical validation and a whitelist mapper. Periodic math adds finite checks, determinant/condition thresholds, safe integer offsets, repeat limits, candidate limits, and multiplication caps.

The renderer performs no fetch, XHR, worker, remote texture, CDN, module import from artifact data, HTML injection, or artifact execution. Supercell rebuilds dispose old graphics resources. Normal UI errors expose only typed summaries.
