# Periodic Measurement Contract

Displayed-position mode measures the explicitly selected periodic images.
Minimum-image mode retains the Phase 10F-17 bounded exact triclinic search and
reports resolved offsets. A selected bond always uses its stored endpoints;
minimum-image mode never silently substitutes another bond endpoint.

Distance is angstrom, angle and signed dihedral are degrees, and UI/artifact
precision is six decimals at most. Degenerate/non-finite input returns typed
unavailable state. Measurement is not authoritative chemistry.
