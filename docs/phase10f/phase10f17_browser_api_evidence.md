# Browser and API Evidence

Evidence is generated by `node apps/web/test/viewer-scene-periodic-browser-evidence.mjs`. It uses the existing live `structure.viewer_3d` job/artifact generator and product API interception, then opens the validated renderer in real browsers.

Cases include minimum-image mode, visible image offsets, replica picking, `2x2x2`, `3x3x3`, reset, mobile touch, lifecycle, console audit, and network isolation. Evidence is under `docs/phase10f/evidence/phase10f17_periodic_crystal_inspection/`.
