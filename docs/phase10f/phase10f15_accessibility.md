# Phase 10F-15 Accessibility Baseline

- renderer region is named `3D Structure Viewer`;
- state uses `role=status` and `aria-live=polite`;
- reset and toggle controls have text names;
- toggles expose `aria-pressed`;
- a textual site/species/bond summary is present;
- a non-color species legend is present;
- canvas has an accessible label and hidden textual equivalent;
- loading, invalid, unsupported, chunk failure, and context loss messages remain readable;
- focus-visible styling and keyboard-operable tabs/buttons are retained;
- reduced-motion preference is used in evidence; the renderer has no continuous animation loop.

Keyboard orbit control and a full WCAG conformance audit remain deferred.
