# Phase 10F-16 Site Inspector Contract

The inspector exposes canonical index, label, element/species, occupancy,
fractional and Cartesian coordinates, source identifier, plus renderer-owned
display radius. Neighbor indices/counts are derived only from existing bounded,
non-authoritative scene bonds. No oxidation state, valence, bond order,
CrystalNN/VoronoiNN environment, or chemistry classification is inferred.
Clipboard actions write escaped plain text and safely absorb permission failure.
