# Periodic Performance Review

Atoms remain grouped by species into instanced meshes. Bonds use one bounded line geometry and the display cell uses one line geometry. Chromium evidence records 32 atoms for `2x2x2` and 108 atoms for `3x3x3`, with one atom instanced mesh and three draw calls in the measured four-site case.

No universal FPS claim is made. Acceptance is bounded completion, finite metrics, responsive interactions, one canvas/context, and clean reset/rebuild.
