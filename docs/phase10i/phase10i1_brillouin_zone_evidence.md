# Phase 10I-1 Evidence and Readiness

Evidence is stored under
`docs/phase10i/evidence/phase10i1_brillouin_zone_adapter/` and is regenerated by
`uv run python scripts/generate_phase10i1_brillouin_zone_adapter_evidence.py`.

## Captured Flow

The generator uses the real deterministic planner, persisted AnalysisPlan,
QueueWorkerRuntime, adapter registry, local artifact exporter, artifact
repository, and Phase 10I validators. It captures simple cubic, hexagonal,
triclinic, conventional BCC, primitive BCC, singular-lattice rejection, and
non-periodic ASE input rejection. Valid cases produce all six artifacts;
invalid cases produce none. The preview contract capture and PlannerWorkbench
component test use those real simple-cubic payloads and assert fixed JSON tabs
with no canvas, iframe, script, or renderer initialization.

The evidence bundle excludes random IDs, timestamps, temporary roots, absolute
paths, secrets, and external URLs. It records scientific artifact hashes,
validator results, primitive/conventional equivalence, canonical replay,
runtime statuses, event classes, and security assertions.
