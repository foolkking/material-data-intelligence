# Phase 10I-1 Brillouin Zone Adapter Evidence

Sanitized persisted planner/runtime captures for simple cubic, hexagonal, triclinic, and equivalent conventional/primitive BCC inputs, plus typed singular-lattice and non-periodic rejection. All scientific artifacts are inert JSON validated by the Phase 10I contracts. The existing generic JSON preview is the only UI consumer in this phase; no renderer, browser GPU path, external asset, or network request is included.

Replay with `uv run python scripts/generate_phase10i1_brillouin_zone_adapter_evidence.py`.
