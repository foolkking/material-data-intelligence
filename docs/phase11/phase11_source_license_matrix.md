# Phase 11 Source License Matrix

License status and scientific reference strength are independent axes. Repository-owned retained bytes are recorded as `REPOSITORY_OWNED`/`VENDOR_ALLOWED`; official-example materials with unclear redistribution terms remain `LICENSE_REVIEW_REQUIRED` and `REFERENCE_ONLY`. Public visibility is not treated as redistribution permission.

The generated matrix records every 11-1 reference disposition and does not vendor external bytes.
