# Phase 11 Revalidation Trigger Policy

Numeric scientific validation must be reconsidered when any of these changes:

- Tool scientific version or algorithm;
- scientific parameter-default semantics;
- Artifact scientific contract;
- unit or reference semantics;
- scientific parser semantics;
- a dependency version when that dependency is computation authority;
- fixture expected values or tolerance;
- scientific identity model.

CSS, typography, layout, non-scientific wording, and presentation order normally do not invalidate numeric validation. They can still require browser, accessibility, interaction, and evidence regression.

Historical evidence is never rebound to the latest Tool, dependency, resource, or tolerance.
