# Phase 11 Reference Provenance Policy

Every authoritative reference records a stable reference ID, reference type, capability, source organization/project and version, source file/document identity, retained URL metadata, license status, original checksum, transformation status, normalized fixture identity, expected values or invariants, units, tolerance owner, verdict, and evidence path.

If expected values are generated by the same algorithm or library under test, the record is `SELF_REFERENCE`. It may validate regression, serialization, identity, and determinism, but not independent correctness. Different scientific algorithms, such as CrystalNN and VoronoiNN, are not required to be numerically equal.

Phase 11-0 performs no external downloads or scientific API calls. Phase 11-1 may acquire only reviewer-approved static official sources. Arbitrary notebook execution, downloaded script execution, and automated external scientific API orchestration remain prohibited.

Evidence can be reused only when Tool/version, scientific contract, fixture hash, expected values, units, tolerance, and locked computation-authority dependency identity match.
