# Phase 11 Final Tool Coverage Matrix

The authoritative machine-readable matrix is
`evidence/phase11_4_honest_tool_input_example_coverage/tool_coverage_matrix.json`.
It is generated from the live 62-entry Registry and contains one row per exact Tool ID/version.

Coverage is intentionally conservative: retained runtime and regression evidence is indexed as
`MAPPING_ONLY` until a governed independent, official-derived, or analytic reference satisfies the
Phase 11 coverage criteria. This does not demote the existing software validation level.
