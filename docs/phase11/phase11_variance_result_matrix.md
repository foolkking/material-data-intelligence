# Phase 11 Variance Result Matrix

- Scientific identity and units: `EXACT` required.
- Persisted invariant output: `EXACT` or sealed `TOLERANCE_BOUNDED` only.
- Browser layout, antialiasing, tooltip placement, and WebGL pixels: `DISPLAY_ONLY_VARIANCE` where payload identity is unchanged.
- macOS: `NOT_CURRENT_RELEASE_TARGET`.
- Four Phase 11-2 reference-limited cases: `KNOWN_LIMITATION`, excluded from Phase 11-3.

No new epsilon or pass-driven tolerance adjustment is allowed.
