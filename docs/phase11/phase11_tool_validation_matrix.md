# Phase 11 Tool Validation Matrix

The canonical 62-row matrix is [tool_validation_matrix.json](evidence/phase11_0_validation_baseline_reconciliation/tool_validation_matrix.json). It is generated from the three live Registry manifests and reconciled against the Adapter registry. Documentation-only lists are not Registry authority.

Each row records role, input contracts, Artifact outputs, scientific authority, Adapter disposition, algorithm identity, current validation level, reference types and independence, all validation axes, evidence references, and gaps. There are zero duplicate or unclassified Registry rows.

The nine Phase 10N professional Tools are present at exact version `0.1.0`. The full inventory also covers composition, statistics, dataset intelligence, materials ML, structure summaries and visualization data, static RDF and theoretical XRD, trajectory presentation, phonons, Brillouin zone, and volumetric analysis.

Registry declaration and Runtime registration are separate facts. A Registry entry without a current Adapter is recorded as non-executable and is not promoted by mapping or presentation evidence.
