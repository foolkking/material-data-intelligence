# Phase 10H-3 Frequency Domain Policy

The default shared domain is the union of validated band and DOS ranges so
neither source is silently clipped. A bounded manual range changes display only
and never mutates artifacts or compatibility. Intersection is not the default
because it can hide imaginary or high-frequency content.

Ordinary range differences produce a stable warning. Invalid, non-finite,
reversed, or over-cap domains are rejected.
