# Phase 10H-4 Non-Gamma Modes

Non-Gamma reconstruction uses `2*pi*q_fractional.cell_image`. A future animated
periodic wave requires a bounded commensurate supercell chosen by an approved
solver. This phase does not solve commensurability, generate a supercell,
replicate bonds, or render atoms; it only fixes the required phase semantics and
bounded image-offset validation.
