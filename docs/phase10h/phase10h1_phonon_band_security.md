# Phase 10H-1 Phonon Band Security

Trust changes only after source parsing and canonical validation. YAML object
construction, aliases, tags, recursion amplification, nonfinite numbers,
unknown fields, URLs, private paths, HTML, JavaScript, callbacks, shaders,
modules, archives, pickle, shell, notebook, and solver execution are rejected.

The browser maps whitelisted canonical numeric arrays and application-owned
labels/styles. It does not consume artifact plot code or remote assets. Hard
contract caps and lower explicit preview budgets bound CPU, memory, traces, and
DOM rows. Invalid input creates no partial artifacts and never initializes
Plotly. Browser evidence records zero external requests and no console errors.
