# Phase 10H Branch and Degeneracy Identity

`branch_index` is contiguous and preserves source order. It is not a claim of continuous physical connectivity through crossings. Validation does not sort by frequency, exchange branches, track eigenvectors, or merge numerical degeneracies.

Version 1 requires `branch_scope = full` and exactly `3 * atom_count` branches. Every branch contains one finite THz value per q-point.

Degeneracy groups are optional, source-declared records keyed by q-point and a sorted set of at least two branch indices. Groups cannot overlap at the same q-point, reorder, or create a new branch identity. Eigenvector identity and degenerate-subspace basis semantics are deferred.
