# Phonon DOS Security

Source text has byte, row, column, numeric, and projection caps and cannot load
objects, plugins, URLs, modules, shaders, HTML, or callbacks. Identity,
normalization, units, and broadening use closed fields.

The browser never executes artifact plot data and loads Plotly locally only
after validation. Evidence blocks external requests and checks console errors,
external scripts, iframes, JavaScript URIs, and inline handlers. No dependency
was added.
