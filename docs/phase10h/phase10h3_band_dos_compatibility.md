# Phase 10H-3 Band/DOS Compatibility

Checks run in the fixed `COMBINED_CHECK_ORDER` declared by the Python contract.
`compatible` means no scientific conversion was required. `convertible` is
limited to approved frequency conversion with the reciprocal DOS-density
Jacobian and integral invariance. `incompatible` stops composition before
artifacts are persisted.

Structure, atom order, cell lineage, source/force constants, imaginary
encoding, zero tolerance, NAC, and normalization mismatches are not warnings.
Partial ASR or lineage metadata and ordinary frequency-range differences may be
warnings only when required identities still pass.
