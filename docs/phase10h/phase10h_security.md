# Phase 10H Security Boundary

Phonon artifacts are untrusted inert data until the application-owned validator accepts them. Exact object fields, enum units, bounded arrays, finite numbers, stable identity, metadata byte caps, and warning allowlists define the trust transition.

The contracts reject JavaScript, HTML, callbacks, modules, shaders, executable formulas, `eval`, prototype keys, external URLs/assets, private paths, arbitrary unit expressions, non-finite values, deep metadata, and cap multiplication overflow. Security flags must explicitly state no JavaScript, HTML, executable content, external URLs, or external assets.

No network, filesystem access, notebook/script execution, telemetry, external API, or real LLM path is part of validation. Error results contain typed codes and counts, not payload arrays, stack traces, paths, or secrets.
