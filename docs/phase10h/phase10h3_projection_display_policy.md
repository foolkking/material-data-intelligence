# Phase 10H-3 Projection Display Policy

Total DOS is always the default. Users may select one validated atom or species
projection from the bounded artifact. Projection identity and completeness are
reported exactly as supplied. The UI does not aggregate arbitrary projections,
infer directional components, or treat a partial set as complete.

The contract allows at most four visible projections; the initial UI renders
one selected projection plus total DOS for clarity and bounded trace count.
