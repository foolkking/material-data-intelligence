# Phase 10H-3 Accessibility and Mobile

The product is a named region with textual summary, keyboard-operable tabs,
projection selector, compatibility table, bounded data tables, download
buttons, and polite renderer status. Meaning does not rely only on color:
panels, axes, units, names, compatibility codes, zero line, and imaginary-region
text remain available.

The narrow layout constrains toolbar, tabs, tables, and plot without horizontal
page overflow. Evidence covers Chromium touch viewport and reduced motion.
Physical assistive-technology and broad-device testing remain deferred.
