# Phonon DOS Plot Contract

Only independently validated canonical DOS is mapped to locally bundled Plotly
core/scatter. Frequency is x, DOS is y, zero and negative regions remain
visible, total DOS is default, and at most one selected projection is added.

The frontend refuses more than 100,000 plotted values and retains table/JSON.
Artifact plot JSON is inert evidence, not executable configuration. Chunk
failure is typed and unmount purges Plotly and its resize listener.
