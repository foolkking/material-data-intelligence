# Phase 10H-4 Caps

V1 caps are 512 atoms, 4096 modes, 6,291,456 complex Cartesian components,
1 MB metadata, 64 MB artifact bytes, 32 warnings, and absolute cell-image
offset 16. Products exceeding caps are rejected before unbounded allocation.
No artifact can select tolerances, search bounds, normalization, phase policy,
or display budgets.
