# Phase 10H-3 Shared Frequency Axis

The combined plot is one Plotly figure with two x domains and one shared y
axis. Band traces use q-path distance; DOS traces use density; frequency is THz
on the common y axis. The zero line and negative-frequency imaginary region
span both panels. Band discontinuities and tick order are retained.

Artifact plot data is inert. The frontend maps validated fields into
application-owned traces, colors, layout, hover text, and export settings.
