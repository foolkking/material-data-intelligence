# Phase 10H-1 Phonon Band Accessibility

The preview has a named region, visible atom/branch/q-point/segment/frequency
summary, keyboard tabs, an aria-labelled plot, a polite status announcement,
and a semantic table fallback. Species identity and frequency range are not
communicated by color alone. Mobile uses a single-column summary and a bounded
scrolling table without document-level horizontal overflow or scroll capture.

Automated evidence covers Chromium, Firefox, WebKit, reduced motion, and a
390x844 touch viewport. Physical assistive-technology labs remain deferred.
