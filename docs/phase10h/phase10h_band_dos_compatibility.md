# Phase 10H Band and DOS Compatibility

Compatibility has three results: `compatible`, `convertible`, or `incompatible`.

Direct compatibility requires the same structure SHA-256, atom count/order/species, THz unit, negative-real imaginary encoding, zero tolerance, calculation lineage, force-constant source, cell relation, input hash, and NAC metadata. Approved frequency units can be classified as convertible before canonicalization. Structure, source, or NAC disagreement is incompatible.

The check does not combine arrays, infer shared provenance, normalize DOS, or reconcile different NAC directions. Phase 10H-3 may consume this result but is not implemented here.
