# Phase 10H-4 Security

Validators use exact fields, finite numbers, bounded arrays/depth, stable
allowlists, SHA-256 bindings, and inert security flags. Artifact JS/HTML/CSS,
callbacks, URLs, modules, shaders, prototype keys, local paths, notebooks,
scripts, external workers, and network references are rejected. No dependency,
tool, planner, runtime, browser renderer, external API, or real LLM is added.
