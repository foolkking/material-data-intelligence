# Phase 10H-4 Mass Weighting

Atomic masses are positive finite values in unified atomic mass units with an
explicit source/reference. Allowed sources are source-provided, canonical
structure mass, approved standard atomic weight, or isotope-specific metadata.
Real-space directions use `u_i=e_i/sqrt(m_i)`. Atomic number substitution,
hidden isotope averaging, kg/amu mixing, and double unweighting are forbidden.
