Pre-M0 is a current-product reality audit, not a claim that every visual or
complex-data requirement is already qualified. Existing G browser evidence and
focused frontend tests are retained as evidence; this ledger separates
behavioral semantics from deep visual/complex-content qualification.

## Explicit limits

This audit includes a current Chromium desktop and 390×844 browser replay
against the current frontend, with API responses supplied by a bounded
scientific-product fixture. It also reuses G's persisted service-backed browser
journeys for lifecycle continuity. Browser automation is interaction and
presentation evidence, not human-quality usability proof. The audit does not
claim support beyond current registry/parser/viewer caps or long-running scale
qualification.
