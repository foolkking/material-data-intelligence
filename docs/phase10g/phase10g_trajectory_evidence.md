# Evidence

Evidence is generated deterministically by `uv run python scripts/generate_phase10g_contract_evidence.py` into `docs/phase10g/evidence/phase10g_trajectory_contract/`.

It includes machine-readable schema/policy records, fixed-lattice MD, variable-lattice triclinic relaxation, unwrapped diffusion-like and nonperiodic fixtures, typed invalid cases, summary/manifest validation, Python/TypeScript comparison, deterministic hash replay, security/network audits, and SHA-256 inventory. No large trajectory or browser claim is included because no trajectory viewer exists.
