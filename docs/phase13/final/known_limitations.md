# Known Limitations

- **LIM-001 (scientific-validation):** Tool availability is not independent reference validation.
- **LIM-002 (cross-platform):** Linux/Windows invariant replay is not independent cross-platform numeric validation.
- **LIM-003 (browser):** Tested browser engines are not universal browser certification.
- **LIM-004 (phonon-input):** Typed Band/DOS imports are limited; generic YAML/JSON is mapping-only.
- **LIM-005 (provider):** Optional DeepSeek verification is not science or reference validation.
- **LIM-006 (recipe):** Recipes are declarative and non-executable.
- **LIM-007 (xrd):** Peak correspondence is not phase confirmation or refinement.
- **LIM-008 (diffusion):** Diffusion is an estimate over the selected fit window.
