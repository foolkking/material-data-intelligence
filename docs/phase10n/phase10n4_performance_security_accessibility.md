# Phase 10N-4 Performance, Security, and Accessibility

Caps: 200 frames, 5,000 atoms, 2,000,000 RDF pair evaluations, 2,048 bins/lags, 4,096 origins per lag, 10,000 fit points, 32 MiB output, Registry timeout, and bounded JSON depth/size. Computation is server-side NumPy over validated in-memory resources. No network, shell, subprocess, notebook, arbitrary path, dynamic module, arbitrary Python, HTML, JavaScript, iframe, or external URL authority exists.

The frontend performs no unwrapping, RDF, MSD, or fit. Tables expose every numeric result; controls are named, keyboard reachable, focus-visible, and not color-only. Mobile reflows without horizontal page overflow, controls meet the existing 44 px target policy, reduced motion is respected, and plots are not the sole result authority. Lifecycle evidence requires 50 switches with zero listener, observer, animation-loop, chart, canvas, duplicate request, and stale response growth.
