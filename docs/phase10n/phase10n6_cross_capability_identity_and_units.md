# Phase 10N-6 Cross-Capability Identity and Units

Scientific identity is bound to immutable resource hashes, Artifact checksums, contract
and Tool versions, parameter hashes and domain identities. Array position, display label,
filename, nearest/fuzzy matching and latest-result selection have no authority.

Canonical units remain angstrom, degree, dimensionless coordination and RDF, degree 2theta,
angstrom wavelength, ps, angstrom squared, angstrom squared per ps and eV. DOS normalization
remains source-qualified. N6 introduces no conversion.
