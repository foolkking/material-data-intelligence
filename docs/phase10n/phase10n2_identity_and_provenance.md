# Phase 10N-2 Identity And Provenance

Environment identity binds exact source N1 Artifact/checksum, immutable structure hash,
site ID, source algorithm, geometry reference identity and N2 parameter hash. Vertex
identity is the exact N1 neighbor relation identity. Polyhedron identity hashes the
canonical sorted vertex identities plus N2 contract and algorithm. A face identity is the
canonical sorted triplet of vertex identities.

Structure/site/neighbor/periodic-image/checksum/catalog identities use exact equality.
Site index is valid only inside one immutable structure hash. No display label, row,
screen vertex, nearest point, latest Artifact or cross-algorithm fuzzy relation is an
identity authority.
