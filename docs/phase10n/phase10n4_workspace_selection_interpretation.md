# Phase 10N-4 Workspace, Selection, and Interpretation

The existing Workspace adds one trajectory analytics renderer for RDF, MSD, and diffusion Artifacts. It loads metadata first and scientific payload only for an active Artifact. Tables are the numeric accessibility authority; plots are presentation only and perform no calculation.

Selection adds exact RDF pair/bin, MSD species/lag, and diffusion window/diagnostic identities. Every N4 selection binds project, dataset/version, job, trajectory, Artifact ID/checksum, and the persisted sub-result identity. Plot pixels, rows, nearest points, species display labels, and latest Artifact are not identities.

The deterministic interpretation projector exposes bounded persisted counts, values, coverage, units, diagnostic status, warnings, and limitations. It cannot unwrap, compute RDF/MSD, select a fit window, fit diffusion, or change qualification thresholds. Reports preserve diagnostics and state that diffusion is estimated only over the selected fit window. Recipes remain declarative and non-executable.
