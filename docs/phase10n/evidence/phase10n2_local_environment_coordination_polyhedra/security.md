# Security

N2 consumes inert validated JSON only. It has no arbitrary code, shell,
filesystem, notebook, external network, dynamic module, Artifact HTML/JS/iframe,
Recipe, recommendation or recovery authority. Exact Project/Job/Artifact scope,
checksum, structure hash, site identity and periodic-image validation reject
foreign, stale, malformed, path-shaped and credential-shaped input. Oxidation
state and bond-valence analysis are out of scope.
