# Accessibility

The N2 panel provides a semantic environment table, exact site buttons,
Inspector tables for metrics/vertices/faces, a text fallback for the visual
overlay, visible status text, and geometry-qualified wording. It does not make
WebGL the only path to the result. The real browser matrix exercised keyboard
site activation, exact selection status, named Inspector/figure controls,
reduced motion, a 200% reflow-equivalent viewport with zero overflow, mobile
focus trap/return, and a 44 CSS px minimum visible touch target.
