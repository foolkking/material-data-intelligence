# Phase 10N-2 Artifact Contract

The single strict payload `phase10n2.local_environment_polyhedra.v1` records Tool,
algorithm, reference catalog, exact Structure scope, exact source N1 Artifact identity
and checksum, source algorithm and parameter hash, N2 resolved parameters, site results,
classification candidates/status, canonical vertices/faces, approved metrics, coverage,
warnings, diagnostics, provenance, limits and inert security markers.

It references but does not copy the full N1 Artifact or Structure. `table_json` is the
dependency-visible scientific payload. `summary_md` and `recipe_json` are bounded static
projections. No HTML, JavaScript, URL, module or executable field is accepted.
