# Phase 10N-5 Reference and Tolerance Evidence

Fixtures cover gapped/gapless, direct/indirect, spin, path breaks, missing Fermi,
total/spin/projected DOS, completeness and compatible/incompatible combined cases. Frozen
tolerances are energy abs `1e-8 eV`, relative `1e-10`, Fermi compatibility `1e-8 eV`,
k-point `1e-10`, gap/DOS regression `1e-8`, and classification threshold `1e-5 eV`.
Hashes, IDs, versions and parameter hashes use exact equality.
