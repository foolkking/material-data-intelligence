# Phase 10N-2 Performance, Security And Accessibility

Hard caps are 5,000 evaluated sites, 64 neighbors/vertices per site, 32 references per
site, 128 faces per polyhedron, 16 MiB output and 180 seconds. Matching is bounded
`O(n^2 log n)` per site and performs no permutation search. Small, medium, near-cap and
over-cap fixtures record wall time and payload size as development evidence.

Inputs are inert JSON plus the exact immutable Structure. There is no code, shell,
filesystem, notebook, dynamic module, network, HTML or JavaScript authority. Checksums,
project/job/structure scope and finite numeric bounds are enforced before geometry work.

Environment/metric tables are keyboard accessible and remain available without WebGL.
Controls are named, state is non-color, mobile targets are at least 44px, reflow works at
200%, reduced motion is honored and heavy-viewer lifecycle retains zero growth.
