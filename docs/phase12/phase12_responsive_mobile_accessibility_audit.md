# Responsive, Mobile and Accessibility Audit

Audit targets are 1440x900, 1280x720 and 390x844; mobile retains one active
panel, context drawer, panel switcher and Inspector bottom sheet. Phase 12-6
owns keyboard/focus, named controls, non-color state, table alternatives, 44px
targets, 200% reflow and reduced motion. WCAG-like AA is an engineering target,
not a certification claim.
