# Phase 12-2 Global Navigation Specification

| Destination | Control | Existing authority |
| --- | --- | --- |
| Home | link to `/` | Planner route |
| Data | action button | Dataset/Profile dialog |
| Analyses | action button | Conversation/Plan tab |
| Workspaces | action button | Existing Workspace history API |
| Reports | action button | Results/Export tab |
| Settings | action button | Existing provider/settings dialog |

Active state is textually identifiable, keyboard reachable and not color-only.
No destination implies an unsupported capability. `/workspaces/{workspaceId}`
remains the canonical persisted Workspace deep link.
