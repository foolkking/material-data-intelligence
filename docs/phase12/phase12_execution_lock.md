# Phase 12 Execution Lock

Phase 12 redesigns presentation, interaction, hierarchy and product experience;
it does not redesign scientific authority. Registry 62, DataProfile 2.4,
AnalysisIntent 1.0, EligibilityResolution 1.0, AnalysisPlan 0.1/0.2, migration
0007, Tool/Artifact contracts, Workspace identity, exact selection identity,
Report/Recipe authority, scientific units/claims and Phase 11 coverage are locked.

Forbidden shortcuts: browser scientific recomputation, latest/nearest/label/filename
identity, hiding limitations, unsupported-without-explanation, and recommendation
as automatic execution. Phase 12-1 and Phase 12-2 are complete; Phase 12-3 is
the only active authorized task and Phase 12-4 remains reviewer-gated.

## Phase 12-1 Design System Scope

Phase 12-1 may change existing frontend presentation tokens, generic shared
controls and representative shared surfaces. It must not change route/IA
ownership, Planner flow, Workspace grouping, viewer interaction, scientific
visualization semantics, backend/API/database behavior, scientific identity,
Phase 11 coverage or provider policy. Scientific series colors remain frozen.

## Phase 12-2 Navigation and Planner Scope

Phase 12-2 may change global navigation presentation, Planner information
hierarchy, progressive disclosure, clarification context, execution feedback and
typed error recovery. Existing routes and server authorities remain canonical.
No new public API family, database migration, dependency, scientific Tool,
AnalysisPlan semantics, queue behavior, Workspace identity or selection identity
may be introduced.

## Phase 12-3 Workspace and Viewer Scope

Phase 12-3 may recompose Workspace navigation presentation around results and
group Plan/Execution as Analysis. It may provide shared scientific viewer
chrome, table alternatives, warning placement and responsive framing. It must
preserve the nine persisted panel kinds, exact panel URLs, server Workspace
identity, Artifact/renderer registry, exact Selection contract, lazy loading,
scientific values, units, series colors and all backend behavior. Findings,
Evidence, Inspector and Report workflow redesign remain owned by later phases.
