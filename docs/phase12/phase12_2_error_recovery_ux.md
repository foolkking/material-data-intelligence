# Phase 12-2 Error and Recovery UX

Planner failures answer four questions: what happened, why, what the user can
do, and what was preserved. Existing typed errors, validation diagnostics and
safe details remain the source authority. Recovery actions are guidance or
existing selection/dialog actions; they never bypass Eligibility, PlanValidator,
QueueWorkerRuntime or provider policy.

`UX-008` is closed with evidence. Backend error codes and scientific semantics
are unchanged.
