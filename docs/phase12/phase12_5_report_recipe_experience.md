# Phase 12-5 Report and Recipe Experience

Phase 12-5 presents Report composition as an exact, human-readable workflow:
discover eligible persisted sources, select and order them, preserve mandatory
disclosures, preview without writes, explicitly confirm immutable finalization,
then inspect history and server-authorized exports. Source identity and
eligibility remain server authority.

Recipe presentation now explains how the result was produced before exposing
the exact inert declaration. It has no Run action and creates no Plan, Job,
ToolCall, queue message, or scientific authority.
