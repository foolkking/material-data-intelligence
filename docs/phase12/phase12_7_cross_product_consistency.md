# Phase 12-7 Cross-Product Consistency

The accepted Global IA is Home, Data, Analyses, Workspaces, Reports and
Settings. The accepted Workspace IA is Overview, Data, Analysis, Results,
Findings, Evidence, Report and Advanced. Phase 12-7 changes neither.

Planner stages remain meaning-first; scientific viewers use shared title,
toolbar, status, warning, loading and table-alternative chrome; Findings and
Evidence retain exact trust paths; Inspector retains Summary, Scientific
Details and Provenance; Report and Recipe retain mandatory disclosures and
non-executable replay semantics. The 18-term en-US/zh-CN glossary and ten DS2
status families have no unresolved required mapping.
