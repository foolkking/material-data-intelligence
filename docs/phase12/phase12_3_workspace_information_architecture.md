# Phase 12-3 Workspace Information Architecture

The existing nine persisted panel kinds remain the runtime authority. The
presentation groups are:

| User concept | Existing panel destination |
|---|---|
| Overview | `OVERVIEW` |
| Data | `DATA` |
| Analysis | `PLAN`, `EXECUTION` |
| Results | `SCIENTIFIC_RESULT` |
| Findings | `FINDINGS` |
| Evidence | `EVIDENCE` |
| Report | `REPORT` |
| Advanced / Provenance | `PROVENANCE` |

No panel ID, URL query, server layout revision or selection token changes.
Advanced disclosure is a presentation choice; provenance remains directly
reachable and exact.
