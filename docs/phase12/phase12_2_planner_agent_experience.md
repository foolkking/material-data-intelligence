# Phase 12-2 Planner / Agent Experience

The Planner remains a bounded client for server-owned intent, eligibility, plan
and runtime authority. The user-facing presentation is progressive disclosure:

1. active data context;
2. understood intent and clarification choices;
3. human-readable analysis approach;
4. execution stage and Agent Timeline;
5. result and Workspace transition.

Developer Details continue to expose exact plan IDs, Tool IDs, bindings, hashes
and raw declarations. The browser performs no scientific calculation,
replanning, provider call or queue operation.
