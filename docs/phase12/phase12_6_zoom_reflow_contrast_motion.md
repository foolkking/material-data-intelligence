# Phase 12-6 Zoom, Reflow, Contrast, and Motion

At 200% zoom/reflow, essential actions and state labels remain reachable;
scientific tables may scroll within their bounded container but the document
does not gain unrecoverable horizontal overflow. English, Chinese, long Tool
IDs, hashes, warnings and limitations wrap without changing canonical values.

The target is WCAG-like AA engineering contrast, not certification. Focus and
status remain visible in forced-colors mode. `prefers-reduced-motion` suppresses
new transitions and animation repetition; scientific animation controls and
data semantics are unchanged.
