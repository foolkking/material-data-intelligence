# Phase 12-6 Mobile Product Experience

The mobile authority is unchanged: one active panel, context/navigation drawer,
panel switcher, and Inspector bottom sheet. Planner input, status, recovery and
the Workspace result remain reachable at `390x844`; desktop density is not
inflated to satisfy touch requirements.

Canonical mobile journeys `M1` through `M14` cover empty and ready Planner,
clarification, unsupported and running states, completed and partial Workspace,
scientific chart and 3D surfaces, trust paths, Report/Recipe, and recovery.
Critical tables use bounded horizontal scrolling and retain numeric/text
alternatives. No compressed three-column desktop layout is used on mobile.
