# Phase 12-6 Screen Reader Semantics

Planner and Workspace expose main, navigation, complementary, heading, form,
status, alert and dialog semantics. Skip links lead to the primary analysis or
active scientific result. Asynchronous intent, eligibility, execution, save,
selection and recovery states use bounded live regions; blocking failures use
alerts.

Evidence authority is DOM/ARIA inspection and browser replay. It is not a real
assistive-technology certification. Scientific charts and 3D scenes retain
tables, metadata, Inspector and exact source records as non-graphical access.
