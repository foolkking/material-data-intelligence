# Phase 12-1 Accessibility Foundation

DS2 standardizes `:focus-visible`, semantic native controls, visible disabled
states, text-bearing status labels, icon-button accessible-name requirements,
44 px mobile control primitives and `prefers-reduced-motion` behavior. Long
scientific labels and identifiers wrap or truncate only with full identity still
available through existing provenance/Inspector paths.

This is `ACCESSIBILITY_FOUNDATION_IMPLEMENTED`, not a claim of complete product
accessibility. Cross-product keyboard, screen-reader, reflow and specialized
viewer closure remains owned by Phase 12-6 and 12-7.
