# Phase 12-1 Scientific Visualization Style Boundary

DS2 may style viewer surroundings, neutral backgrounds, toolbar/panel surfaces,
titles, focus and loading. It does not alter Plotly trace colors, series/category
identity, numeric values, axis/range semantics, Three.js geometry, atom positions,
camera semantics, selection identity or any scientific payload. Specialized viewer
interaction redesign remains Phase 12-3.
