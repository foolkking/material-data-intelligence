# Phase 12-1 Design Token Registry

The canonical machine-readable registry is
[`design_token_registry.json`](evidence/phase12_1_design_system_2_0/design_token_registry.json).
It records primitive and semantic token IDs, values, source, contrast roles,
responsive roles and consumers. The deterministic semantic hash covers tokens,
typography, spacing/density, surfaces, focus/motion and the status mapping.

The canonical spacing rhythm is 4, 8, 12, 16, 24 and 32 px. Regular desktop
controls are 36 px, compact controls 30 px, and reworked mobile/touch controls
are at least 44 px. The typography hierarchy is constrained to page title,
section, panel, body, dense body, label, metadata/caption and identifiers.
