# Phase 12-6 Scientific Visualization Accessibility

Charts retain numeric/table alternatives, keyboard access where a formal
selection identity exists, and exact server Artifact authority. Three-dimensional
surfaces retain text summaries, metadata, warnings, limitations and Inspector
access. Tooltip-critical information is also available by focus or persistent
text.

WebGL and screenshots remain presentation evidence only. No chart, table or 3D
surface recalculates coordination, XRD peaks, RDF, MSD, diffusion, electronic
bands, DOS, PCA, clustering, units or scientific identity.
