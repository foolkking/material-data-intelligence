# Phase 12 Product Experience Principles

P12-EP01 Meaning before mechanism. P12-EP02 Result before Artifact.
P12-EP03 Progressive disclosure. P12-EP04 Scientific limitations are first-class.
P12-EP05 One clear primary action per context. P12-EP06 State is understandable
without color. P12-EP07 Exact identity remains available. P12-EP08 Desktop and
mobile share authority, not necessarily layout. P12-EP09 Heavy viewers remain
active/lazy. P12-EP10 Errors preserve context. P12-EP11 Developer detail is
accessible but subordinate. P12-EP12 UX convenience creates no scientific authority.
