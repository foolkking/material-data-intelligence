# Phase 10M-6 Responsive, Mobile, and Accessibility

Desktop retains header, context/navigation, one active main panel, and one exact Inspector. Mobile uses one active panel with context drawer, panel switcher, Inspector bottom sheet, and a single Report surface. It does not compress the desktop three-column layout.

Drawer/sheet focus is placed, trapped, escaped, and returned to the trigger. Core Save, conflict reload, panel navigation, Pin/Clear/Copy, Report composition/history/export actions remain keyboard reachable. Save/conflict/cap/draft transitions use named status regions and text, not color alone. Charts, tables, WebGL, lineage, warnings, and limitations retain text alternatives.

At 390x844, controls meet 44x44 CSS pixels, exact IDs and long text wrap, and body/root horizontal overflow is zero. Reduced motion and 200% reflow remain supported by bounded layouts.
