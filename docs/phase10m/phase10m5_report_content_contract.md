# Phase 10M-5 Scientific Report Content Contract

Every deterministic Report contains all twelve ordered sections: Title,
Analysis Goal, Dataset and Resource Scope, Methods and Plan, Execution Status,
Selected Results, Grounded Findings, Warnings and Limitations, Failed/Blocked/
Missing Scope, Evidence and Provenance, Environment and References, and Exact
Rerun Recipe Reference. Empty sections retain a typed empty/unavailable state.

Selected results are exact panel, Artifact, approved static figure, or bounded
table references. Claims are admitted only from the validated interpretation
for the same Project/Job/Evidence bundle. Scientific claim text, number, unit,
subject, confidence, and limiting evidence are immutable.

Warnings, limitations, partial coverage, failed steps, blocked dependencies,
missing outputs, stale/unsupported records, provider/validation failures, and
reference limitations are mandatory disclosures and cannot be removed.
User title and captions are bounded inert text and never scientific authority.

WebGL canvas state and browser screenshots are not Report figures. Viewers
without a formal static representation contribute exact Artifact metadata plus
approved text/numeric fallback only.
