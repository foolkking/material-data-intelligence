# Phase 10M-2 Responsive and Accessibility Contract

Desktop uses the sealed global header, collapsible data rail, vertical
Workspace navigation, one active panel, and overlay inspector. Mobile at
390x844 uses one active panel, a data-context/panel-switcher drawer, and an
inspector bottom sheet. It does not shrink the desktop three-column layout.

The current browser evidence confirms semantic `main`, header, navigation,
complementary, region, dialog, heading, and status surfaces; visible focus;
Escape close with focus restoration; 44px minimum Workspace button targets;
and zero horizontal document overflow in Chromium, Firefox, WebKit, and mobile
Chromium. Charts and WebGL renderers remain M4 scope.
